# TaskVerse

Private, offline productivity tools for Android — document, data, image and PDF tools that run entirely on your device.

## Download

**Latest version: 1.0.2** — [Download TaskVerse-1.0.2.apk](https://github.com/Syed-Ibrahim-11/TaskVerse/releases/download/v1.0.2/TaskVerse-1.0.2.apk)

- Android 6.0 or newer
- 3.5 MB, universal build
- No account, no ads, no uploads — your files stay on your phone

## How to install

1. Download the APK on your Android phone.
2. Open the downloaded file. If Android warns about installing unknown apps, tap **Settings** and allow your browser or file manager to install apps from this source.
3. Tap **Install**, then **Open**.

## Updates

Every new version is published as a new release. Download the newest APK and install it over the old one — your data stays intact because the app keeps the same package name and signing certificate. There is no need to uninstall first (except when moving from the old debug build, which used a different certificate).

## Privacy

TaskVerse processes everything on-device and keeps no analytics or tracking. Files you open are never uploaded anywhere; results are saved straight to your phone's Downloads folder.
